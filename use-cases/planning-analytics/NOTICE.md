# Provenance

The uploaded repository LICENSE is retained unchanged. This appliance uses the
Software Hub-derived Bob 2.x runtime with the accepted behavior through Patch 45,
and the Planning Analytics domain materials assembled from the supplied guide.
PAA-3.0.0 replaces the rejected installer/maintenance design, removes local hash
admission in launch/guide checks, applies the requested local 0777 policy, and
extends the cyan renderer for recognized uncolored input frames.

Unchanged and changed modules are distinguished in the distribution's
`audit/runtime-lineage.json`. Those hashes are informational and are never read
by maintenance or the runtime. No IBM product certification is implied.
