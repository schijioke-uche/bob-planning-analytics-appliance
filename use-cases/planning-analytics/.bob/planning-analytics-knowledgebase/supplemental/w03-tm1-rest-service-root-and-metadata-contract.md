# W03 - TM1 REST service-root and metadata contract

Source category: additional public IBM research, separate from the supplied guide.
Review date: 2026-10-08. Access: search-extract.

IBM examples append entity paths and $metadata to an explicit service root. Local HTTPPortNumber controls the REST port. Example hosts/ports are illustrative. The packaged probe accepts a user-supplied verified service root, performs GET only and does not infer SaaS routing.
