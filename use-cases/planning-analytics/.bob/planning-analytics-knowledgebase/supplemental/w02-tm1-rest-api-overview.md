# W02 - TM1 REST API overview

Source category: additional public IBM research, separate from the supplied guide.
Review date: 2026-10-08. Access: search-extract.

TM1 REST uses OData v4 for model access and modification. Read access and writes are distinct operations; the metadata describes the service model. Do not substitute Workspace or SaaS administration APIs for a TM1 database service.

Source: https://www.ibm.com/docs/en/planning-analytics/2.1.0?topic=analytics-tm1-rest-api
