# W06 - SaaS automation identity

Source category: additional public IBM research, separate from the supplied guide.
Review date: 2026-10-08. Access: search-extract.

IBM directs SaaS users to invite an appropriate directory user, grant access and generate that user's API key rather than create a legacy noninteractive account. The exact authorization-header scheme and service endpoint must still be taken from the installed offering's contract.

Source: https://www.ibm.com/support/pages/how-do-i-create-noninteractive-account-planning-analytics-service
