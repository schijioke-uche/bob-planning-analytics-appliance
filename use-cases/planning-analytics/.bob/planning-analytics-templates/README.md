# Planning Analytics implementation templates

These are project-authored templates, not IBM installation media, executable server imports or certified production configurations. Use the applicable offering/version documentation, substitute approved values, validate in nonproduction and obtain explicit authorization before live changes. `pa-tool.py scaffold` copies the JSON/Markdown contracts into a new, non-overwriting named project folder. Rule and MDX examples require native TM1 validation; offline Python tests do not compile them.
